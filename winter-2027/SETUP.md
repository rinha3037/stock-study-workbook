# PK수학 2027 겨울방학 특강 — 선착순 신청 페이지 설정

학부모용 페이지: `winter-2027/index.html` (GitHub Pages 주소: https://rinha3037.github.io/stock-study-workbook/winter-2027/)
신청 내역 저장소: 원장님의 **Google 스프레드시트** (Apps Script 웹앱이 접수·정원 계산을 담당)

```
학부모 휴대폰 ──신청──▶ Apps Script(정원 9명 잠금 확인) ──기록──▶ Google 시트 '신청내역'
                                                                  ▲
                                                원장님이 시트에서 확인·결제안내 체크
```

## 1. 스프레드시트와 Apps Script 만들기 (10분)

1. Google 드라이브에서 새 스프레드시트를 만듭니다. (예: `2027 겨울특강 신청`)
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 `winter-2027/apps-script/Code.gs` 내용을 붙여넣은 뒤 저장합니다.
4. 필요하면 맨 위 설정을 고칩니다.
   - `OPEN_AT`: 접수 시작 시각. 예) `'2026-12-01T10:00:00+09:00'` — 이 시각 전에는 신청 버튼이 잠깁니다.
   - `CLOSE_AT`: 접수 마감 시각 (비우면 계속 접수).
   - `CLASSES`의 `capacity`: 반별 정원 (기본 9명).
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - 배포 → 권한 승인 (“확인되지 않은 앱” 경고가 나오면 고급 → 이동)
6. 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/…/exec`)을 복사합니다.

## 2. 신청 페이지에 연결

`winter-2027/index.html` 아래쪽 `CONFIG`를 고칩니다.

```js
SCRIPT_URL: "https://script.google.com/macros/s/…/exec",   // 1-6에서 복사한 주소
PERIOD: "2027년 1월 5일 ~ 2월 6일 (5주)",                     // 실제 특강 기간
CONTACT: "02-000-0000",                                     // 학원 전화번호
```

`SCRIPT_URL`이 비어 있으면 상단에 “미리보기 모드” 띠가 뜨고 실제로 접수되지 않습니다 (브라우저에만 저장).
반 이름·수강료·시간표 문구도 같은 `CONFIG.CLASSES`에서 바꿀 수 있습니다. 반 코드(T1~T3)와 정원은 `Code.gs`와 맞춰 주세요.

수정 후 커밋하면 GitHub Pages에 1~2분 뒤 반영됩니다. 학부모께는 위 주소를 문자/카톡으로 보내면 됩니다.

## 3. 시트에서 관리하기

첫 신청이 들어오면 `신청내역` 시트가 자동으로 생깁니다. (먼저 만들려면 시트 메뉴 **PK수학 특강 → 신청내역 시트 만들기**)

| 열 | 쓰는 법 |
|---|---|
| 접수번호 / 접수일시 | 선착순 순서 그대로 쌓입니다. 정렬해도 됩니다. |
| 상태 | `접수`(자리 확보) · `대기` · `취소`. **취소로 바꾸면 그 자리가 페이지에 잔여석으로 다시 열립니다.** 대기자를 올릴 때는 `대기 → 접수`로 바꿉니다. |
| 결제안내 | 결제창 안내를 보낸 학생에 체크 |
| 결제완료 | 결제 확인 후 체크 |
| 관리자 메모 | 자유롭게 |

- 잔여석 = 정원 − `접수` 상태 인원. 페이지는 30초마다 자동 갱신됩니다.
- 학부모는 페이지 하단 **신청 확인**에서 학생 이름+연락처로 본인 상태(접수/대기 n번/결제 안내 여부)만 볼 수 있고, 다른 학생 정보는 볼 수 없습니다.
- 같은 학생(이름+학부모 연락처)이 `접수`/`대기` 상태로 있으면 중복 신청이 막힙니다. 반 변경은 시트에서 직접 고쳐 주세요(반·반코드 둘 다).
- 결제 안내 일정이 되면 시트를 `상태 = 접수`로 필터해 학부모 연락처로 결제 링크를 보내고 `결제안내`에 체크하면 됩니다.

## 4. Code.gs를 수정했다면

Apps Script에서 **배포 → 배포 관리 → (연필) 수정 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. URL은 그대로 유지됩니다.

## 참고

- 반 구성·수강료는 운영안의 추천안(3타임 × 2시간) 기준입니다: 1타임 중등부 월·수·금 15회 40만 원, 2·3타임 고등부 매일 25회 65만 원, 반별 9명.
- 개인정보 보유 기간 문구(특강 종료 후 6개월)는 `index.html`의 안내 표에서 학원 방침에 맞게 고쳐 주세요.
